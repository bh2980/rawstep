# T-005 actuator와 허용 키 제한

완료일: `2026-04-11`

## 작업 ID

`T-005`

## 목적

에이전트가 허용된 키만 누를 수 있게 만들고, 입력 비용을 정확히 센다.

## 입력/의존

- 선행 작업: `T-002`, `T-004`
- 기준 문서: `docs/01-CONTRACTS.md`, `docs/02-RUNTIME_LOOP.md`

## 해야 할 일

- `Actuator` 클래스를 만든다.
- `press(key)` 에서 whitelist 검사를 한다.
- 허용되지 않은 키는 명시적 에러를 던진다.
- 눌린 총 키 수를 센다.
- 키별 분포도 센다.
- action 1회당 cost delta가 0 또는 1이라는 전제를 깨지 않게 한다.

## 하지 말아야 할 일

- 문자열 자유입력을 허용하지 않는다.
- 클릭, 마우스 이동, 스크립트 실행 같은 API를 넣지 않는다.
- 비용 집계를 trace 쪽으로 흩뿌리지 않는다. 입력 사실은 actuator가 가장 먼저 안다.

## 완료 조건

- 허용 키는 정상적으로 눌린다.
- 허용되지 않은 키는 즉시 실패한다.
- 비용과 키별 카운트가 누락 없이 쌓인다.

## 테스트 방법

- 허용 키 1개를 눌러 cost가 1 오르는지 확인
- 서로 다른 키를 눌러 keyCounts가 맞는지 확인
- 허용되지 않은 키로 에러가 나는지 확인
