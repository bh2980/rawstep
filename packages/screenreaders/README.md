# @rawstep/screenreaders

Rawstep screenreaders workspace.

Part of the Rawstep monorepo. Build locally with `pnpm install --frozen-lockfile` and `npm run build` at the workspace root. Browser executables and native screen readers are separate prerequisites. See [CONTRIBUTING.md](../../CONTRIBUTING.md).

## Third-party corpus data

The MIT license covers this package's own code, not the third-party material it bundles. The compiled evidence catalog holds selected reported observations and derived metadata from Accessibility Supported and ARIA-AT; their notices are in the root [THIRD-PARTY-NOTICES.md](../../THIRD-PARTY-NOTICES.md). How the simulator uses them is in [src/mock-voiceover/README.md](./src/mock-voiceover/README.md).
