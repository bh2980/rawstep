# @rawstep/cli

Rawstep cli workspace. It provides the `rawstep` commands: `init`, `ui`, `run`, `hints`, `report`, `analyze` and `doctor`. Configuration is `rawstep.config.json`, shared with the dashboard; see the [config reference](../../docs/reference/config.md) and the [CLI reference](../../docs/reference/cli.md).

Part of the Rawstep monorepo. Build locally with `pnpm install --frozen-lockfile` and `npm run build` at the workspace root. Browser executables and native screen readers are separate prerequisites. See [CONTRIBUTING.md](../../CONTRIBUTING.md).
